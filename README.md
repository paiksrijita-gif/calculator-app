# Calculator

A simple calculator built with plain HTML, CSS and JavaScript — no build step, no dependencies.

## Features

- Add, subtract, multiply, divide with correct order of operations (× ÷ before + −)
- Percent, ± sign toggle, backspace, clear
- Keyboard support: digits, `+ - * /`, `Enter` or `=`, `Backspace`, `Esc`
- Light and dark mode (follows your system setting)
- Works on phones and desktops

## Run locally

Open `index.html` in your browser. That's it.

## Deploy

This is a static site, so Vercel deploys it as-is — import the GitHub repo at
[vercel.com/new](https://vercel.com/new) and click **Deploy** (no settings to change).
